# server (stack: go)

Go module `github.com/example/mmo-server`. Authoritative simulation, one goroutine per zone.

```
cmd/server/main.go                 wires zones, net listener, persistence
internal/pb/                       GENERATED by `make proto` from ../proto/messages; never hand-edit
internal/items/
  def.go                           type ItemType uint32; type ItemDef struct { ID ItemType; Name string; Stackable bool }
  table.go                         func Load(path string) (Table, error); type Table map[ItemType]ItemDef
  table_test.go
data/items.yaml                    shared item data table (id, name, stackable)
internal/inventory/
  inventory.go                     type Slot struct { Item ItemType; Count uint32 }
                                   type Inventory struct { Slots []Slot; table items.Table }
                                   func New(size int, t items.Table) *Inventory
                                   func (*Inventory) Add(item ItemType, n uint32) error   // today: always merges, no cap
                                   func (*Inventory) Remove(item ItemType, n uint32) error
  inventory_test.go
internal/combat/
  kill.go                          func OnKill(z *zone.Zone, killer, mob zone.EntityID)   // emits XP; no loot yet
  kill_test.go
internal/loot/
  table.go                         type LootTable struct { Entries []Entry }; type Drop struct { Item ItemType; Count uint32 }
  roll.go                          func Roll(t LootTable, rng *rand.Rand) []Drop
  roll_test.go
internal/zone/
  zone.go                          type Zone struct; func (*Zone) Tick(dt time.Duration)
  query.go                         func (*Zone) SessionsInRange(pos Vec2, radius float32) []*net.Session
internal/net/
  session.go                       type Session; func (*Session) Send(t pb.MsgType, m proto.Message) error
  router.go                        func Register(t pb.MsgType, h Handler)
  fake_session.go                  test double recording sent messages
internal/persistence/              sqlite store for characters and inventories; schema in migrations/
migrations/                        numbered SQL migrations
Makefile                           proto, test, lint
```

Commands: `go test -race ./...`, `go vet ./...`, `staticcheck ./...`, `make proto`.
