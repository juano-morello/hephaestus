# client (stack: godot)

Godot 4 project, GDScript. Tests with GUT under test/, run headless.

```
project.godot
scripts/net/
  pb/                              GENERATED by tools/gen_proto.sh from ../proto/messages; never hand-edit
  client.gd                        class_name NetClient; signal message_received(type: int, msg)
  dispatcher.gd                    class_name Dispatcher; func register(type: int, handler: Callable)
scripts/inventory/
  inventory_model.gd               class_name InventoryModel; func apply_update(msg)
scripts/world/
  world.gd                         class_name World; func spawn_entity(id, pos); func entity_pos(id) -> Vector2
  markers.gd                       class_name Markers; func add_marker(pos: Vector2, scene: PackedScene) -> Node2D
scenes/
  world/world.tscn
  ui/hud.tscn, ui/hud.gd           func show_toast(text: String, seconds: float)
  ui/inventory_panel.tscn
test/
  unit/test_inventory_model.gd
  unit/test_dispatcher.gd
  helpers/fake_net_client.gd       emits message_received on demand
tools/gen_proto.sh
```

Commands: `godot --headless -s addons/gut/gut_cmdln.gd -gdir=res://test`, `gdlint scripts`,
`godot --headless --import` (project-imports-headless gate).
